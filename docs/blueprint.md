# **App Name**: PortfoForge

## Core Features:

- Public Portfolio Display: Showcase projects, blogs, skills, achievements, testimonials, and contact information to visitors.
- Admin Authentication & Authorization: Secure login and logout functionality for the administrator, protecting the dashboard and its features.
- Dynamic Content Management (CRUD): Admin dashboard to create, read, update, and delete projects, blogs, and testimonials, including rich text support for blogs.
- Resume & Profile Media Upload: Admin can upload a profile image and update their resume PDF, making them dynamically available on the public site.
- Contact Form & Message Storage: Visitors can submit contact forms, with messages securely stored in a database.
- AI-Assisted Content Tool: A tool within the admin dashboard to generate descriptions or summaries for projects and blog posts, based on keywords or brief inputs.

## Style Guidelines:

- Color scheme: Dark theme to convey professionalism and focus. Primary accent color: A vibrant blue (#6893F7) for headings and interactive elements, providing a modern feel against a dark background.
- Background color: A deep, desaturated slate blue (#20222B) for the main content areas, promoting readability and focus.
- Accent color: A lighter, energetic cyan (#91D4F8) for subtle highlights, links, and call-to-action buttons, creating visual interest.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-savvy, and impactful appearance.
- Body font: 'Inter' (sans-serif) for high readability and a clean, objective aesthetic across all text content, including blog posts and project descriptions.
- Utilize a consistent set of minimalist, line-based icons to maintain a clean and professional look throughout the site and admin panel.
- A clean, spacious layout emphasizing content clarity and readability, with adaptive responsiveness for optimal viewing on all device types.
- Subtle and purposeful animations on hover states and page transitions, designed to enhance user experience without distraction, reinforcing a polished feel.
